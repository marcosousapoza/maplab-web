# Contributing

Pull Ready work from the Maplab Kanban board, use a focused branch, preserve
accessibility and responsive behavior, and link the pull request to its issue. Done
means checks, tests, production build, documentation, and review pass.

Pin WASM upgrades with `npm install --save-exact
@marcosousapoza/maplab-wasm@X.Y.Z`. Publishing requires a matching version tag and
the trusted `publish-package.yml` workflow in the public WASM repository.
